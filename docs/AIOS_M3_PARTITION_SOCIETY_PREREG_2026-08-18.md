# 사전등록 — M3: 분할형 사회는 단일 context를 이기는가 (2026-08-18)

**상태: 사전등록. 데이터를 보기 전에 동결한다.** 개정은 append-only Errata로만.

## 0. 왜 이것이 G5의 재개봉이 아닌가 (`prereg_superseded`)

G5는 사회를 죽였다(society 0.4062 vs solo_ledger 0.4688, kill rule 발동). **닫힌 결정을
데이터 없이 다시 여는 것은 정지규칙 교체다.** 그러므로 무엇이 바뀌었는지 먼저 적는다.

G5가 시험한 것은 **투표형**이었다 — 같은 과제를 넘겨받아 이어서 하는 다른 agent.
그 축의 값은 이후 독립적으로 측정됐고 **없다**:

```
이종 패널 16 substrate  유효 독립표 1.75
이종 패널 20 substrate  유효 독립표 1.90
copyness (2026-08-18)   같은 모델·다른 사적기록에서 결정 발산 초과 −0.018 (단, 식별 불가)
```

이 실험이 시험하는 것은 **분할형**이다 — 서로 다른 질문에 각자의 영역으로 답하는 전문가들.
**새 관측**: 우리 코퍼스는 **11,718,417 토큰**이고 200k context의 **58.6배**다
(`docs` 층만 3.6M = 18배). 즉 단일 agent가 전체를 동시에 볼 수 없다는 것이 **가정이 아니라
측정된 사실**이며, 이는 G5에서 시험된 적 없는 제약이다.

이 구별이 중요한 이유: 분할은 단일 agent가 가질 수 있었던 정보를 나누는 게 아니라
**구조적으로 한 번에 들 수 없는 것**을 든다. A1의 *"얼어붙은 라우터가 적응형을 이긴다"*가
여기서 무력한 것도 같은 이유다 — **얼어붙은 테이블도 context에 들어가야 한다.**

## 1. 팔 (3개)

```
A  단일 agent + 전체 검색      코퍼스 전체에 대한 retrieval. 정보 접근은 제한 없음.
B  단일 agent + 최선의 압축    층별 요약 인덱스를 context에 상주. C와 무관한 구현자가 최선을 다함.
C  N 분할 전문가 + 라우터      층(organ) 단위 분할, 각자 자기 층만 상주. 라우터가 질문을 배분.
```

**분할 원칙은 지금 동결한다: `layer`(organ) 단위.** 결과를 보고 분할을 바꾸면 그건 튜닝이다.

**B가 이 설계의 전부다.** B 없이 C가 A를 이기면 우리가 발견한 것은 사회가 아니라 **압축**이다.

## 2. 과제와 오라클 — 최적화기가 만질 수 없는 곳에서

과제는 **그래프에서 기계적으로 생성**하고 정답은 **결정론적 DB 질의**로 계산한다.

```
생성기   graph에서 샘플링 (구조적, 모델이 쓰지 않음)
검증기   sqlite 질의 (결정론적, 모델이 쓰지 않음)
피험자   A/B/C의 agent들
```

세 역할이 분리되므로 루프가 자기 과제를 만들고 자기 검증기를 쓰고 자기를 채점하는 형태가
아니다(2026-07-17 지시문의 anti-reward-hacking 요건).

과제 유형(동결):
- **cross-layer 인용 추적**: X를 인용하는 문서 중 층이 다른 것과, 그 문서가 X의 무엇을 바꿨는가
- **supersede 체인**: X를 무효화한 것과 그 근거 문서
- **증거 대조**: 두 층의 서로 다른 기록이 같은 수치를 다르게 말하는 지점

## 3. 실행 전 게이트 (하나라도 실패하면 돌리지 않는다)

**G0 — 과제가 실제로 단일 context를 초과할 것.**
각 질문에 필요한 증거 문서들의 합이 `> 1 context`이고, **≥2개 층**에 걸칠 것.
초과하지 않으면 C는 정의상 무의미하고, 그 질문은 풀에서 뺀다(사후가 아니라 생성 시점에).

**G1 — 행동 분산.** 정답의 주변분포에서 **최빈값 ≤ 60%**.
*오늘 이걸 어겨서 copyness가 INDETERMINATE로 끝났다*(RETRY 90/96%). 같은 실수를 두 번
하지 않기 위해 게이트로 승격한다. 위반하면 ΔU=0은 **측정된 0이 아니라 식별 불가**다.

**G2 — 계측 캘리브레이션** (`scripts/aios_instrument.py`로 강제):
```
양성 대조  한 층만으로 답하는 질문 → C가 이겨야 한다. 아니면 라우터가 고장이다.
음성 대조  코퍼스 없이 일반지식으로 답하는 질문 → 세 팔이 같아야 한다.
           다르면 오염(모델이 이미 답을 안다)이고 측정은 코퍼스에 대한 것이 아니다.
반례       주장의 전제를 만족하는 적대 사례를 실행하고 in_scope=True를 증명할 것
```

## 4. 지표와 kill rule

주 지표: **외부 오라클이 판정한 정답률.** 짝지음(같은 질문) McNemar 정확검정.

```
C ≤ B                              ⟹ 발견한 것은 압축이지 사회가 아니다. 분할 폐기.
(C−B) 단측 95% 하한 < δ_min(5pp)   ⟹ 기본값 OFF · 성능 주장 없음
라우터 정확도가 우연 수준           ⟹ 분할이 학습 가능하지 않다. 분할 원칙 자체를 폐기.
C ≤ A                              ⟹ 검색이 이긴다. 상주 전문가의 근거 없음.
```

부차(보고하되 주를 대체하지 않음): 토큰·지연·모델 호출 수, 라우터 오배분 시 손실.

## 5. 이 실험이 답하지 못하는 것 (미리 적는다)

- **발산의 유용성은 여기서 안 나온다.** C가 이겨도 그건 *커버리지*의 값이지
  *다양성*의 값이 아니다. 두 기제를 섞어 해석하지 않는다.
- **일반화 단위는 우리 코퍼스다.** 다른 코퍼스에서 층 분할이 통한다는 주장은 하지 않는다.
- **모델은 고정한다.** 팔 간 모델을 바꾸면 그건 모델 실험이지 harness 실험이 아니다.

가설에 가장 부합하는 질문일수록 최대 층(`.aios`)에 쏠린다. **더 좁히면 G1이 깨진다** —
