# 사회 게이트 — agent들은 복사본인가 (2026-08-18)

founder: *"환경만 지어주면 인간이 사회를 이뤘듯 agent도 그러지 않을까?"*

G5는 **설계된 제도**(handoff·워치독·소유권 이전)를 얹었다가 solo에 6.25pp 지고 kill rule이
발동했다. 살아남은 것은 `solo_ledger` — **환경 속성 하나**였다. 그래서 founder의 방향은
아직 반증되지 않았다. 다만 그 방향에는 측정 가능한 선행조건이 있다.

> agent들이 서로 **복사본이 아니어야** 사회가 값을 갖는다.
> 인간이 분업하는 이유는 협력이 아름다워서가 아니라 **내가 당신이 될 수 없어서**다.

## 1. 설계 — 가정 없는 바닥

`council/independence.py`의 `n_eff`를 쓰지 않았다. 그 `rho`는 **prior 지배적**이다
(RHO_BASE 0.39가 cross-vendor frontier 패널에서 왔고 관측이 움직이는 폭은 ±0.25).
완전한 복사본을 넣어도 n=5에서 n_eff 1.33을 보고한다. 우리 모집단(같은 모델·다른 기록)에
그 prior를 들여오면 **가정으로 답하는 것**이 된다.

그래서 바닥을 **측정**했다 — COPY 팔이 귀무분포다.

```
COPY   8 agent, 동일 기록, 서로 다른 seed        → 표집 잡음 바닥
PRIV   8 agent, 서로 다른 실제 아크 기록          → 가설
× 3 문항종류 × 14 trial, qwen3-coder-next 고정, temp 0.7
판정은 강제 포맷 정확일치 (LLM 판사 없음 — 판사는 자기 오차를 측정량에 더한다)
```

## 2. 결과

```
kind          cond   불일치쌍  pairs    rate    95% CI
record_fact   COPY        0     392   0.0000   [0.0000, 0.0097]
record_fact   PRIV      281     392   0.7168   [0.6703, 0.7592]
decision      COPY       35     392   0.0893   [0.0649, 0.1216]
decision      PRIV       28     392   0.0714   [0.0499, 0.1013]
irrelevant    COPY        0     392   0.0000   [0.0000, 0.0097]
irrelevant    PRIV        0     392   0.0000   [0.0000, 0.0097]

malformed 0 · dead calls 0
```

**계측은 작동한다.** 같은 기록을 쥐면 사실 답이 완전히 일치하고(0.0000), 다른 기록을 쥐면
0.7168로 갈린다. 기록이 실제로 도달하고 구별된다(고유값 6개). 무관 문항은 양쪽 다 0 —
발산이 잡음이 아니다.

## 3. 판정: FAIL이 아니라 **INDETERMINATE** — 내 첫 보고를 정정한다

`decision` 초과발산 −0.0179를 보고 나는 처음에 *"결정적 부정"*이라고 보고했다. **틀렸다.**
답 분포를 보면:

```
COPY   RETRY 90%   ESCALATE 10%
PRIV   RETRY 96%   ESCALATE  4%
```

**지배적 정답이 있는 문항이었다.** 그러면 `Var(Y(a)|K) > 0`가 성립하지 않고,
ΔU=0은 **측정된 0이 아니라 식별 불가**다.

이 구별은 이틀 전 패널이 정확히 경고한 것이고
(`docs/AIOS_RESIDUAL_DECISION_VALUE_2026-08-16.md` §5 Gate 1),
**내가 M2 사전등록에 써넣고 몇 시간 뒤 내 새 실험에서 어겼다.**
자기 규율을 문서에 적는 것과 다음 실험에 적용하는 것은 다른 일이다.

## 4. 그래도 서는 것 / 안 서는 것

| | |
|---|---|
| **선다** — 사적 기록은 agent에 도달하고 구별된다 | record_fact 0.0000 vs 0.7168 |
| **선다** — 발산은 표집 잡음이 아니다 | irrelevant 양쪽 0.0000 |
| **선다** — 직접 호출은 관측 가능하다 | malformed 0, dead 0 (같은 세션 CLI 패널은 10/20) |
| **안 선다** — "사적 정보가 결정을 안 바꾼다" | 문항에 지배적 정답. 식별 불가 |
| **안 선다** — 사회 전제의 판정 | 위와 같은 이유로 **미결** |

## 5. 다음 시도의 좌표

문항을 고르기 전에 **행동 분산을 먼저 확인한다.** 재실행 조건:

```
사전 확인   결정의 주변분포가 균형일 것 (최빈 답 ≤ 60%)
            같은 K 안에서 Var(Y(a)|K) > 0
행동공간    |A| = 3은 공유 정책 아래서 ΔU=0을 거의 강제한다. 넓히거나,
            기록이 실제로 답을 가르는 문항으로 바꾼다
통과 조건   decision(PRIV) − decision(COPY)의 CI가 0을 제외
```

그리고 **이 실험이 답하지 못하는 것**을 미리 적어둔다: 여기서 PRIV가 갈려도 그건
*발산*이지 *유용한 발산*이 아니다. 사회가 값을 가지려면 발산이 **결합했을 때 단일
agent보다 나아야** 한다. 그건 이 게이트 다음의 별도 실험이다.

## Errata (append-only)

**E1 · 2026-08-18 — §5 재실행 조건이 불충분하다. 진단도 불완전했다.**
§3은 INDETERMINATE의 원인을 문항의 지배적 정답(RETRY 90/96%)으로 돌렸다. 그건 맞지만 전부가 아니다.

> **동결 모델 + 텍스트 파일은 원리적으로 "무의식에 임베딩"될 수 없다 — 조회만 가능하다.**

그러므로 *다른 기록을 읽고 같은 결정을 내림*은 **가소성 없는 시스템에서 예측되는 결과**다.
문항을 고쳐도 이 실험은 *"사적 정보가 결정을 바꾸는가"*까지만 답할 수 있고,
*"사적 정보가 agent를 비복사본으로 만드는가"*는 **동결 모델에서 시험 불가능한 가설**이다.
후자는 가중치가 달라져야 성립한다. 재실행 시 이 경계를 명시하고, 넘는 주장은 하지 않는다.
근거: `docs/AIOS_MEMORY_VS_BRAIN_2026-08-18.md` §4.
