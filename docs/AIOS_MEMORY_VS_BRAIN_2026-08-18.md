# 인간 기억과 비교했을 때 무엇이 빠졌나 (2026-08-18)

founder: *"자주 쓰지 않는 기억은 잊혀지고, 자주 쓰는 것은 무의식으로 임베딩된다. 뇌 가소성도
있고. 그것과 이번 실험을 비교하면 뭐가 부족했나?"*

측정부터 했다. 네 가지가 빠졌고, 넷째가 copyness 실패의 진짜 원인이다.

## 1. 사용 신호가 아예 없다 (실측)

```
memoryOS 노드 397,854개 중 retrieval_count 를 가진 것: 0
존재하는 것은 compute_recency_decay — captured_at 기준, 즉 나이로 감쇠
```

**매일 쓰는 기억과 한 번도 안 쓴 기억이 같은 속도로 약해진다.** 인간과 정반대 축이다.
스키마에 감쇠는 있는데 감쇠의 **축이 틀렸다**.

그리고 이것이 같은 날 hop 측정과 **같은 문장**이다
(`docs/AIOS_GRAPH_TRAVERSAL_2026-08-18.md`): 프론티어가 h4→h5에서 29%→84%로 터지는 이유는
**모든 엣지가 동등**하기 때문이다. 인간 기억이 터지지 않는 이유는 엣지가 **사용으로 가중**되기
때문이다. *"병목은 도달 가능성이 아니라 순서다"*와 *"자주 쓰는 건 임베딩된다"*는 같은 주장이고,
**사용 빈도가 바로 그 순서 신호다.**

## 2. 통합(consolidation)이 없다 — 강한 링크가 아니라 다른 시스템이다

인간은 반복 사용 시 표상이 명시적 조회(서술)에서 암묵적 기술(절차)로 **이주**한다.
저장이 세지는 게 아니라 **저장 종류가 바뀐다.**

우리 시스템의 저장 양식은 **조회 하나뿐**이고, *"자주 회수됨 → 더 이상 회수가 불필요"*로 가는
경로가 없다. M2 사전등록은 가설을 둘로 쪼갰는데(`H_info` 새 정보 / `H_comp` 더 쌈),
통합은 **세 번째**다:

```
H_info   회수가 K에 없는 정보를 준다
H_comp   회수가 같은 정보를 더 싸게 준다
H_cons   회수가 필요 없어진다 — 연산의 비용이 아니라 연산 자체가 사라진다   ← 빠져 있었다
```

⟹ M2 Errata로 반영한다.

## 3. 망각이 없다 — 그리고 append-only는 HARD 불변식이다

인간은 잊고, **망각이 회수를 감당 가능하게 유지한다.** 우리 그래프에 dangling 45,474건이
쌓인 것은 아무것도 감쇠하지 않기 때문이다.

DNA 불변식 #3(append-only audit)은 편집 불가다. 해소는 층을 나누는 것이다:

> **원장은 append-only, 색인은 감쇠해도 된다.**

기록은 전부 보존되고(불변식 유지), 회수 구조만 잊는다. 인간도 기억이 삭제되는 게 아니라
**접근 경로가 약해진다** — 같은 구조다.

## 4. 가소성이 없다 — 그리고 이것이 copyness 실패의 진짜 원인이다

우리 실험은 전부 모델을 동결한다. harness 실험으로는 방법론적으로 옳다. 그러나:

> **동결된 모델 + 텍스트 파일은 원리적으로 "무의식에 임베딩"될 수 없다. 조회만 가능하다.**

그러므로 copyness 결과 — *서로 다른 기록을 읽고 같은 결정을 내림* — 은 **가소성 없는
시스템에서 예측되는 바로 그것**이다. 문항의 지배적 정답(RETRY 90/96%)이 유일한 원인이라고
적었던 것은 **불완전한 진단**이었다.

> **사적 context는 주머니 속 메모지고, 사적 이력은 다른 뇌다.**
> 가중치를 공유하고 context만 다른 한, agent는 복사본을 벗어날 수 없다.

⟹ **copyness 재실행 조건을 고친다.** 문항만 고쳐서는 안 된다. 동결 모델에서는
*"사적 정보가 agent를 비복사본으로 만드는가"*가 **애초에 시험 불가능한 가설**임을 명시한다.
동결 모델에서 시험 가능한 것은 *"사적 정보가 결정을 바꾸는가"*까지이고, 그 위의 주장은
가중치가 달라져야 성립한다.

그리고 이것은 fine-tune을 *"언젠가의 moat"*에서
**"agent를 진짜 비복사본으로 만드는 유일한 기제"**로 격상시킨다.

## 5. 순서 — 셋은 넷째 없이 못 한다

**사용을 재지 않으면 사용으로 가중할 수 없다.** 신호가 0인 상태가 모든 것의 선행 조건이다.

```
1  회수 이벤트 기록          node_id · task · hit/miss · ts — 신호 0 상태를 끝낸다
2  색인 가중치를 사용 기반으로  원장은 그대로 (§3의 층 분리)
3  값싼 baseline 게이트        빈도·중심성이 프론티어 폭발을 줄이는지 먼저.
                              sheaf는 그 다음 — 오늘 세 번째로 쓰는 arm B 구조
4  가소성                     별개 축. 동결 모델로는 시험 불가.
                              M3가 답할 수 있는 질문이 아니다 — 명시하고 분리한다
```
