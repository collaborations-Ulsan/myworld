# 생성적 헌장 — 거부는 로그가 아니라 채무다 (2026-08-19)

founder: *"kill 하고 끝이 아니라 생성적 헌장을 가져."*

## 1. 오늘 지은 것이 전부 부정이었다

```
스폰 거절 · 종료 거절 · 능력 거절 · 핑퐁 차단 · 인용 금지 · NO-GO ·
고아 판정 · 소비 불인정 · 반례 없는 주장 불인정
```

하나씩은 옳고, 합치면 **아무것도 안 하는 쪽으로 수렴하는 시스템**이다. 그리고 그 수렴이
이미 숫자에 있다:

```
공장 4 : 내 컨텍스트 21          42개가 working에 고임
organ 넷 7일간 커밋 0            grounding 소비율 0.00
```

**NO만 말하는 헌장은 반쪽이다.** 나머지 반은 **채무**다 — 부정 소견은 그것을 긍정으로
바꿀 일을 *발행*해야 한다. 로그의 제안이 아니라 **같은 큐에 들어가 같은 게이트를 받는 태스크**로.

## 2. 그래서 kill rule이 생성기가 된다

| 소견 | 갚아야 할 것 |
|---|---|
| 아무도 안 가진 능력 | 보유자를 세운다 |
| 모든 보유자가 거부 | 소유자에게 핸들러를 준다 |
| 생산됐으나 소비 안 됨 | 소비 불가능한 경로를 교체한다 |
| 고아율이 기준 초과 | 잇거나 **사유와 함께** 아카이브한다 |
| dangling 참조 | 인용을 고치거나 뺀다 |
| kill rule 발동 | 그것을 되열 실험을 사전등록한다 |
| 미검증 주장 | **열리는 링크**로 그라운딩한다 |

`scripts/aios_charter.py`. 첫 sweep이 오늘의 부정 소견을 그대로 일로 바꿨다:

```
6 finding → 5 obligation (1건은 상한으로 이월)
  hivemind 고아 49.0% > 35%        → 5,159건을 잇거나 아카이브        a6a904cc3e04
  experiments 고아 33.5% > 20%     → 189건                            633db4d86203
  adversarial.refute 소비 0/19회   → 경로 교체                        ea872df85968
  grounding.external 소비 0/16회   → 경로 교체                        bb105fc10981
```

## 3. 헌장 자신에게 거는 두 제약

**상한**: sweep당 5건. **완료보다 빠르게 발행하는 헌장은 핑퐁의 다른 모양**이다 —
오늘 라우터가 같은 태스크를 1분에 4번 튕긴 그 실패와 구조가 같다. 이월분은 이월했다고 말한다.

**depth+1**: 채무는 depth 1에서 시작한다. 수리가 수리의 수리를 낳는 무한을 `MAX_DEPTH`가 막는다.

## 4. 그리고 빈 sweep의 의미를 미리 못박는다

소견이 0이면 출력은 이렇게 말한다:

> *"갚을 것이 없다는 뜻이지, 잘 돌고 있다는 뜻은 아니다.
> 게이트가 아무것도 못 잡는 상태와 잡을 것이 없는 상태는 다르다."*

**침묵을 통과로 읽는 것**이 이번 아크에서 가장 자주 물린 실패다 —
0바이트 산출물, 안 걸린 한국어 트리거, 보유자 없이 영원히 대기한 큐, 조용히 실패한 `up` 명령.
헌장도 같은 방식으로 실패할 수 있으므로 그 문장을 코드에 넣었다.

## 5. 루프에 상설

공장 tick 5회마다 헌장이 돈다. **게이트가 자기 거부를 일감으로 바꾸는 것이 상시 동작**이 되고,
그래야 "무엇을 지을지"가 사람의 기억이 아니라 시스템의 측정에서 나온다.
