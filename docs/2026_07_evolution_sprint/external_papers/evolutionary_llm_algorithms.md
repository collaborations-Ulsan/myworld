# Evolutionary LLM Algorithms & Automated Algorithm Design (2026)

In 2026, the intersection of Large Language Models (LLMs) and Evolutionary Computation (EC) is driving Automated Algorithm Design (AAD). This paradigm shifts from hyperparameter tuning to generating and evolving entire algorithmic pipelines and architectures.

## Key Frameworks and Methodologies
- **LLaMEA (Large Language Model Evolutionary Algorithm):** Generates and refines metaheuristic optimizers. Treats algorithms as individuals in a population and uses LLMs to perform evolutionary operators (crossover/mutation) on code. Benchmarked via IOHprofiler and BLADE.
- **EASE (Effortless Algorithmic Solution Evolution):** A modular framework for closed-loop generation and evaluation. It enables continuous optimization for automated discovery of code and complex pipelines.
- **EvoMAS (Evolutionary Generation of Multi-Agent Systems):** Specializes in automated generation of multi-agent configurations. By evolving the architecture rather than just code, it significantly improves reasoning and tool-use capabilities.
- **AlphaEvolve:** Responsible for discovering new multi-agent learning algorithms (like VAD-CFR, SHOR-PSRO) by structurally modifying underlying code.
- **EvoStage:** Decomposes algorithm design into sequential stages with real-time feedback to mitigate hallucinated designs.
- **CALM (Co-evolution of Algorithms and Language Model):** A hybrid method that fine-tunes the LLM via RL while evolving heuristics, optimizing both the search process and the LLM itself.

## 2026 Architectural Insights
Research highlights a focus on hybrid guidance (combining LLM "verbal" reasoning with benchmark "numerical" feedback), achieving closed-loop autonomy in design, and reducing compute overhead via quantization and local models.
