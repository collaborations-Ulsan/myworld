# 무엇을 알고리즘이 하고 무엇을 agent가 하는가 (2026-08-19)

founder: *"모든 걸 agent가 처리하지 않아도 된다. 시스템적으로 확실하게 algorithmic하게
처리되어야 하는 것들은 그렇게 처리되어야 agent에게 더 편하지 않을까?"*

## 1. 어제 하루의 증거가 그 방향을 지지한다

| 선 것 (알고리즘) | 흔들린 것 (모델이 개입) |
|---|---|
| seam checker — 외부 shell 구현이 같은 root로 통과 | CLI/웹 패널 **10/20 응답** |
| 그래프 감사 · G0/G1 계수 · `can_spawn` 게이트 | `n_eff`의 stance 클러스터링이 LLM 판사 |
| 천장 거절 — 튜플 인덱스 두 개 비교 | muse-glimmer가 "OK" 하나에 **147토큰** |
| copyness 강제포맷 정확일치 (malformed 0) | 오라클이 내용 아닌 **전송형식**을 거부 |

## 2. 그러나 결정론이 정확성을 사주지는 않는다

어제 **내 알고리즘 코드도 다섯 번 틀렸다** — 엔트로피→support 추론, 파서 결함 3종,
`argparse` dest 충돌, 레거시 트리아지가 감사기록을 삭제 후보로, 반례가 전제를 만족하지 않음.

> **결정론이 사주는 것은 정확성이 아니라 디버깅 가능성이다.**
> 틀려도 매번 같은 방식으로 틀리니 찾힌다. 10%씩 무작위로 틀리는 모델은
> 그 자체가 잡히지 않는다.

## 3. 경계 — 어디를 어느 쪽에 두는가

```
agent      무엇을 할지 결정 · 후보 생성 · 비정형 의도 읽기 · 기준을 적을 수 없는 판단
알고리즘   검증 · 게이트 · 측정 · 측정된 사실 위의 라우팅 · 경계 강제
```

**검증이 알고리즘이어야 하는 것은 효율이 아니라 정확성 요건이다.** LLM 검증기는 설득당한다.
2026-07-17 지시문의 anti-reward-hacking 조항이 같은 말이다 — 루프가 자기 과제를 만들고
자기 검증기를 쓰고 자기를 채점하면 그건 지능이 아니라 자기승인 최적화기다.

## 4. 이 원칙을 가장 아픈 곳에 적용했다 — `n_eff`

이 통제 평면에서 가장 많이 인용되는 숫자가 이 시험을 통과하지 못한다.

```
현행 (council/independence.py)
  rho = 0.39 문헌 상수  +0.047 same-family  ±0.25 LLM 판사의 stance 클러스터링
  ⟹ 약 60% 가정 + 40% 한 모델의 의견 + 0% 측정
```

이 숫자로 어제 하루 동안 **패널 기반 인식론을 폐기하는 결정**까지 내렸다.
결정을 내리는 숫자는 측정될 자격이 있다.

**결정론적 대체물은 이미 지어져 있었고 연결만 안 됐다** — copyness의 강제포맷 정확일치다.
판사도 사전도 필요 없다:

```
rho_hat = 1 − 불일치율          독립 시행 간의 일치가 곧 상관이다
n_eff   = n / (1 + (n−1)·rho_hat)   같은 Kish 공식, 측정된 입력
```

`scripts/aios_neff.py`, copyness 본런(8 agent × 14 trial × 392쌍) 위에서:

```
question      cond     rho_hat   n   n_eff
record_fact   COPY      1.0000   8    1.00     ← 완전한 복사본. 방법이 그렇게 말한다
record_fact   PRIV      0.2832   8    2.68     ← 기록이 결정하는 곳에서는 진짜 독립
decision      COPY      0.9107   8    1.08
decision      PRIV      0.9286   8    1.07     ← 독립이 행동에 도달하지 못한다
irrelevant    both      1.0000   8    1.00     ← 발산이 잡음이 아님을 확인
dropped 0 (전 셀)
```

**판사 버전은 첫 줄을 만들 수 없다.** 완전한 복사본을 먹여도 n=5에서 n_eff 1.33이 바닥이다 —
rho의 0.39가 데이터를 보기 전에 이미 정해져 있기 때문이다.

그리고 셋째 줄이 어제 copyness 결과의 **가장 정확한 진술**이다:

> **사적 기록은 사실에 2.68표를 주고 행동에 1.07표를 준다.**

`I(Y;S|K) > 0` 이면서 `ΔU(S|K) = 0`이라는 명제가 두 숫자로 나타난 것이다.
(단 `decision` 문항은 지배적 정답을 가졌으므로 1.07의 일부는 그 탓이다 —
`docs/AIOS_COPYNESS_GATE_2026-08-18.md` §3의 한계가 여기에도 그대로 걸린다.)

## 5. 이 방법이 더 나은 이유 둘 — 정확도가 아니라 성질

- **재생 가능**: 같은 시드 → 같은 숫자. `n_eff`가 변하면 기질이 변한 것이지
  판사의 기분이 변한 것이 아니다.
- **측정된 바닥**: 동일 모델을 자기 자신에게 붙여 남는 불일치가 표집 잡음이다.
  진짜 독립과 디코딩 온도를 가르는 것이 그 바닥이고, 가정으로는 얻을 수 없다.

## 6. 남은 자리 — agent가 필요한 곳

기준을 적을 수 없는 판단은 그대로 agent 몫이다. 어제 정규식이 세 번 틀렸다는 사실이
"비정형 텍스트를 규칙으로 읽는 것"의 비용을 보여준다. 경계는 **"기준을 적을 수 있는가"**이고,
*"이 둘이 같은 답을 냈는가"*는 적을 수 있다.
