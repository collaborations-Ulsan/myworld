# 왜 짓는가 — 그리고 어디서 실제로 더 빨리 도약할 수 있는가 (2026-08-18)

founder가 목적을 다시 진술했다: 대형 제공자의 **게이팅 천장**, agent의 **context 지배**,
세분화된 전문가들의 **사회**, 사용자·하위 agent와의 **유기적 소통**, 동적으로 움직이는
**컴퓨팅 프로세스**, 최종적으로 **완전 개인화 로컬 시스템**과 **그들보다 나은 오픈소스 기여**.
그리고 이유: **그들보다 더 빠르게 기술 비약을 일으키기 위해서.**

## 1. 이 진술이 내 측정을 정정한다 — 나는 틀린 기제를 재고 있었다

`n_eff`(1.75/16, 1.9/20)도 오늘의 copyness 게이트도 **같은 질문에 N명이 얼마나 다르게
답하나**를 잰다. 투표의 이야기다. founder가 말한 것은 다른 것이다.

```
투표형 사회   같은 질문 → N개 답 → 수렴        n_eff가 재는 것. 1.75~1.9. 값이 없다.
분할형 사회   다른 질문 → 각자 자기 영역       context 한계가 강제하는 것. 안 재봤다.
```

**분할형은 내 잔차 게이트를 통과한다.** context 용량은 하드 제약이므로, 분할은 단일 agent가
가질 수 있었던 정보를 나누는 게 아니라 **구조적으로 한 번에 들 수 없는 것**을 든다.
`docs/AIOS_RESIDUAL_DECISION_VALUE_2026-08-16.md` §4(c)의 *"정보적 충분성 ≠ 계산적 충분성"*의
가장 강한 형태이고, *"얼어붙은 라우터가 적응형을 이긴다"*(A1)가 **적용되지 않는** 영역이다 —
얼어붙은 테이블도 context에 들어가야 하기 때문이다.

⟹ G5가 죽인 것은 **투표형 사회**였고, founder가 제안하는 것은 **분할형**이다. 다시 열린다.
단, 열되 사전등록으로 연다(`prereg_superseded`: 새 관측 = 이 기제 구별).

## 2. 게이팅 천장 — 정직한 형태

기업 제공자는 모든 사용자에게 **동시에** 맞는 균일하고 보수적인 정책을 써야 하고, 그 균일함이
정당한 사용자에게 능력 손실로 온다. 이건 사실이고 정당한 동기다.

그러나 로컬로 옮긴다는 것은 **정책을 없애는 게 아니라 내 정책으로 바꾸는 것**이다.
정책 없는 로컬 시스템은 소버린이 아니라 그냥 미검증 시스템이다. 우리가 이미 지은
cage · 부작용 사다리 · revert · `proven()` · `verify_human_grant`의 `unverifiable`이
그 자리를 채우는 물건들이고, 오늘 문서에 적은 문장이 그대로 적용된다:

> **소버린티는 제약의 부재가 아니라, 제약을 우리가 고르고 그것이 실제로 성립함을
> 증명할 수 있는 상태다.**

## 3. "더 빨리 도약한다"가 성립하는 자리 — 그리고 성립하지 않는 자리

| | 판정 |
|---|---|
| 모델 능력 | **불가.** 그들의 컴퓨트를 우리는 못 산다. 양보한다. |
| **harness** | **가능하고, 여기가 전부다.** 모델 고정 시 harness가 10~15%p (측정치). 학습 실행이 없으므로 반복이 싸다. |
| 1인 맞춤 정책 | **가능.** 그들은 전원을 동시에 만족시켜야 하고 우리는 한 명이면 된다. 회피가 아니라 특화다. |
| context 아키텍처 | **가능.** "한 세션 = 한 context"는 그들의 제품 형태지 물리 법칙이 아니다. |
| 자기 것을 죽이기 | **가능.** 사전등록 kill rule로 우리 기능을 실제로 죽일 수 있다. 제품 조직은 어렵다. |

**레버는 harness다.** Terminal-Bench 2.1이 모델만큼 harness를 잰다는 보고가 있고
(Codex CLI 89.5 / Claude Code 89.1), LangChain이 모델 고정에 +13.7%p를 냈다.
harness는 가장 빨리 움직이고 가장 싸게 반복되며 **우리가 소유한** 층이다.

## 4. 그런데 실제 병목은 빌드 속도가 아니다 — 오늘 데이터가 말한다

빠른 반복은 **반복이 옳을 때만** 빠르다. 오늘 하루에 내 계측이 네 번 틀렸다:

```
① 엔트로피 → support 추론          무효 (커밋된 문서에)
② dangling 131,594                파서 결함 3종. 실제 45,474. 3배
③ 레거시 후보 574건               감사 기록을 삭제 대상으로 올림
④ copyness "결정적 부정"          지배적 정답 문항. FAIL 아니라 INDETERMINATE
```

넷 다 **발표 전에** 잡았고 그게 유일하게 다행인 점이다. 그러나 결론은 분명하다:

> **우리의 율속 단계는 빌드가 아니라 측정의 정확성이다.**
> 틀린 방향으로 빠른 루프는 빠르지 않다.

이건 비관이 아니라 병목의 특정이다. 도약하려면 여기를 고쳐야 한다. 처방:
**모든 새 계측은 자기 자신에 대한 반례를 하나 계산한 뒤에 결과를 보고한다**
(오늘 엔트로피 반례가 그 형태였고, 유일하게 즉시 잡힌 것이었다).

**빠진 것 하나가 크다: 분할형 사회를 재는 실험이 없다.** 다음 사전등록의 자리다.

## 6. 다음 사전등록의 골격 (분할형 society)

```
질문   한 context에 안 들어가는 증거를 요구하는 과제에서,
       분할 전문가 + 라우터가 단일 agent + 검색을 이기는가

A  단일 agent + 전체 검색(RAG)        ← 진짜 대조군. 정보는 다 접근 가능
B  단일 agent + 최선의 컨텍스트 압축   ← 강한 대조군 (M2의 arm B와 같은 역할)
C  N 분할 전문가 + 라우터              ← 가설

선행 게이트  과제가 실제로 단일 context를 초과할 것 (초과 안 하면 C는 정의상 무의미)
             Var(정답|과제) > 0 — 오늘 어긴 그것
kill        C ≤ B ⟹ 우리가 발견한 건 압축이지 사회가 아니다
```
